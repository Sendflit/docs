## Install

```bash
go get github.com/Sendflit/sendflit-go
```

Requires Go 1.21 or later.

## Send an email

```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/Sendflit/sendflit-go"
)

func main() {
	sfl := sendflit.New("re_...")

	res, err := sfl.Send(context.Background(), sendflit.Email{
		From:    "you@yourdomain.com",
		To:      "user@example.com",
		Subject: "Confirm your email",
		HTML:    "<p>Click <a href='...'>here</a>.</p>",
	})
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println(res.ID, res.Status)
}
```

Every call takes a `context.Context`, so you can set deadlines and cancel requests.

## Verify webhooks

```go
ok := sendflit.VerifyWebhookSignature("whsec_...", rawBody, r.Header.Get("X-Sendflit-Signature"))
```

## Errors

Failed requests return an `*sendflit.APIError` with a `.Status` field. See [Errors, retries and limits](/reference/errors).
