## Install

<CodeGroup>
```xml Maven
<dependency>
  <groupId>com.sendflit</groupId>
  <artifactId>sendflit</artifactId>
  <version>1.0.0</version>
</dependency>
```
```groovy Gradle
implementation 'com.sendflit:sendflit:1.0.0'
```
</CodeGroup>

Requires Java 17 or later. The SDK uses `java.net.http` and has no other dependencies.

## Send an email

```java
import com.sendflit.SendFlit;

SendFlit sf = SendFlit.builder("re_...").build();

SendFlit.SendResult res = sf.send(SendFlit.Email.builder()
    .from("you@yourdomain.com")
    .to("user@example.com")
    .subject("Confirm your email")
    .html("<p>Click <a href='...'>here</a>.</p>")
    .build());
System.out.println(res.id + " " + res.status);
```

## Attachments and batch send

```java
SendFlit.Email.builder()
    .from("billing@yourdomain.com").to("u@example.com").subject("Receipt")
    .attach("receipt.pdf", pdfBytes, "application/pdf")
    .build();

sf.batch(List.of(emailA, emailB));
```

## Verify webhooks

```java
boolean ok = SendFlit.verifyWebhookSignature(secret, rawBytes, signatureHeader);
```

## Errors

Failed requests throw `SendFlit.SendFlitException`, with `.status` and `.body` fields. Retries cover 429 and 5xx responses, and `Retry-After` is honored.
