## Install

<CodeGroup>
```bash npm
npm install @sendflit/sdk
```
```bash pnpm
pnpm add @sendflit/sdk
```
```bash yarn
yarn add @sendflit/sdk
```
</CodeGroup>

Requires Node.js 18 or later. The SDK uses the built-in `fetch`.

## Send an email

```js
import SendFlit from "@sendflit/sdk";

const sendflit = new SendFlit({ apiKey: process.env.SENDFLIT_API_KEY });

const { id } = await sendflit.send({
  from: "you@yourdomain.com",
  to: "user@example.com",
  subject: "Confirm your email",
  html: "<p>Click <a href='...'>here</a> to confirm.</p>",
});
```

## Attachments

Up to 10 attachments per message, 10 MB each.

```js
await sendflit.send({
  from: "billing@yourdomain.com",
  to: "user@example.com",
  subject: "Your receipt",
  html: "<p>Thanks for your purchase.</p>",
  attachments: [
    { filename: "receipt.pdf", content: pdfBuffer }, // Buffer or Uint8Array
    { filename: "note.txt", content: "plain text is fine" }, // string
  ],
});
```

## Batch send

Send up to 100 emails in one request. Each message gets its own result, so one bad recipient doesn't fail the batch.

```js
const { results } = await sendflit.batch([
  { from: "you@yourdomain.com", to: "a@example.com", subject: "Hi A", html: "<p>A</p>" },
  { from: "you@yourdomain.com", to: "b@example.com", subject: "Hi B", html: "<p>B</p>" },
]);
```

## Templates

```js
await sendflit.send({
  from: "you@yourdomain.com",
  to: "user@example.com",
  templateId: "tmpl_...",
  variables: { name: "Ada" },
});
```

## Scheduled send

Pass an ISO 8601 timestamp.

```js
await sendflit.send({
  from: "you@yourdomain.com",
  to: "user@example.com",
  subject: "Weekly digest",
  html: "<p>...</p>",
  scheduledAt: new Date("2026-09-05T09:00:00Z").toISOString(),
});
```

## Safe retries

Pass an idempotency key as the second argument. Retrying with the same key and body returns the original result instead of sending again. Reusing the key with a different body returns `409`. See [Errors, retries and limits](/reference/errors#idempotency).

```js
await sendflit.send({
  from: "you@yourdomain.com",
  to: "user@example.com",
  subject: "Order confirmed",
  html: "<p>...</p>",
}, `order-${orderId}`);
```

## Verify webhooks

Use the raw request body. Parsing it first changes the bytes and breaks the signature check. See [Webhooks](/reference/webhooks) for the event list.

```js
import express from "express";
import { verifyWebhookSignature } from "@sendflit/sdk";

app.post("/webhooks/sendflit",
  express.raw({ type: "application/json" }),
  (req, res) => {
    if (!verifyWebhookSignature(WEBHOOK_SECRET, req.body, req.headers["x-sendflit-signature"])) {
      return res.status(401).end();
    }
    const event = JSON.parse(req.body);
    if (event.type === "email.bounced") {
      // suppress the address, alert, ...
    }
    res.status(200).end();
  });
```

## Client options

| Option | Default | Notes |
|---|---|---|
| `apiKey` | none | Required. Starts with `re_`. |
| `baseUrl` | `https://api.sendflit.com` | Change only if you run against a different API host. |
| `timeout` | `15000` | Per request, in milliseconds. |
| `maxRetries` | `2` | Retries 429 and 5xx responses with backoff. Honors `Retry-After`. |

## Methods

| Method | Endpoint |
|---|---|
| `send(email, idempotencyKey?)` | `POST /v1/email` |
| `batch(emails, idempotencyKey?)` | `POST /v1/emails/batch` |
| `listEmails({ limit, offset, status })` | `GET /v1/emails` |
| `getEmail(id)` / `cancelEmail(id)` | `GET` / `DELETE /v1/emails/{id}` |
| `addDomain(name)` / `listDomains()` / `verifyDomain(id)` | `/v1/domains` |
| `createTemplate(t)` / `listTemplates()` | `/v1/templates` |
| `addContact(c)` / `listContacts(q)` | `/v1/contacts` |
| `suppress({ email, reason })` | `POST /v1/suppressions` |
| `usage()` / `health()` | `/v1/usage`, `/v1/health` |

## Errors

Failed requests throw a `SendFlitError` with `.status` and `.body`. See [Errors, retries and limits](/reference/errors).

```js
import { SendFlitError } from "@sendflit/sdk";

try {
  await sendflit.send(email);
} catch (err) {
  if (err instanceof SendFlitError) {
    console.error(err.status, err.body);
  }
  throw err;
}
```
