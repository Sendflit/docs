## Install

```bash
dotnet add package SendFlit
```

Requires .NET 6 or later. The SDK uses `System.Text.Json` and `HttpClient`, with no other dependencies.

## Send an email

```csharp
using SendFlit;

await using var sf = new Client("re_...");

var res = await sf.SendAsync(new Email
{
    From = "you@yourdomain.com",
    To = "user@example.com",
    Subject = "Confirm your email",
    Html = "<p>Click <a href='...'>here</a>.</p>",
});
Console.WriteLine($"{res.Id} {res.Status}");
```

## Attachments and batch send

Up to 10 attachments per message, 10 MB each. Up to 100 messages per batch.

```csharp
var email = new Email { From = "billing@yourdomain.com", To = "u@example.com", Subject = "Receipt" };
email.Attach("receipt.pdf", pdfBytes, "application/pdf");

await sf.BatchAsync(new List<Email> { emailA, emailB });
```

## Verify webhooks

```csharp
bool ok = Client.VerifyWebhookSignature(secret, rawBody, signatureHeader);
```

See [Webhooks](/reference/webhooks) for the event list.

## Async and errors

Every call is async and takes a `CancellationToken`. Failed requests throw `SendFlitException`, with `.Status` and `.Body` properties. Retries cover 429 and 5xx responses, and `Retry-After` is honored. See [Errors, retries and limits](/reference/errors).
