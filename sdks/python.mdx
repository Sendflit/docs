## Install

```bash
pip install sendflit
```

Before the package is on PyPI, install from the repository (requires access to the private repo):

```bash
pip install "git+ssh://git@github.com/mehedihassanz/sendflit.git#subdirectory=sdks/python"
```

The SDK has no dependencies beyond the standard library and supports Python 3.9+.

## Send an email

```python
from sendflit import SendFlit

sf = SendFlit(api_key="re_...")  # or: SendFlit("re_...")

res = sf.send(
    from_="you@yourdomain.com",
    to="user@example.com",
    subject="Confirm your email",
    html="<p>Click <a href='...'>here</a> to confirm.</p>",
)
print(res["id"], res["status"])
```

`from` is a Python keyword, so the SDK takes it as `from_`.

## Attachments

Up to 10 attachments per message, 10 MB each.

```python
sf.send(
    from_="billing@yourdomain.com",
    to="user@example.com",
    subject="Your receipt",
    html="<p>Thanks!</p>",
    attachments=[{"filename": "receipt.pdf", "content": pdf_bytes}],

```

## Batch send

Send up to 100 emails in one request. Each message gets its own result.

```python
res = sf.batch([
    {"from": "you@yourdomain.com", "to": "a@example.com", "subject": "Hi A", "html": "<p>A</p>"},
    {"from": "you@yourdomain.com", "to": "b@example.com", "subject": "Hi B", "html": "<p>B</p>"},
])
```

## Templates

```python
sf.send(
    from_="you@yourdomain.com",
    to="user@example.com",
    template_id="tmpl_...",
    variables={"name": "Ada"},
)
```

## Safe retries

Pass an idempotency key. Retrying with the same key and body returns the original result. Reusing the key with a different body returns `409`. See [Errors, retries and limits](/reference/errors#idempotency).

```python
sf.send(
    from_="you@yourdomain.com",
    to="user@example.com",
    subject="Order confirmed",
    html="<p>...</p>",
    idempotency_key=f"order-{order_id}",
)
```

## Verify webhooks

Pass the raw request body, not a parsed copy. See [Webhooks](/reference/webhooks) for the event list.

```python
import json
from flask import request
from sendflit import verify_webhook_signature

@app.post("/webhooks/sendflit")
def hook():
    raw = request.get_data()
    sig = request.headers.get("X-Sendflit-Signature", "")
    if not verify_webhook_signature(WEBHOOK_SECRET, raw, sig):
        return {"error": "invalid signature"}, 401
    event = json.loads(raw)
    if event["type"] == "email.bounced":
        ...
    return "", 200
```

## Methods

| Method | Endpoint |
|---|---|
| `send(**email, idempotency_key=None)` | `POST /v1/email` |
| `batch(emails, idempotency_key=None)` | `POST /v1/emails/batch` |
| `list_emails(limit, offset, status)` | `GET /v1/emails` |
| `get_email(id)` / `cancel_email(id)` | `GET` / `DELETE /v1/emails/{id}` |
| `add_domain(name)` / `list_domains()` / `verify_domain(id)` | `/v1/domains` |
| `create_template(name, subject, html, text)` | `POST /v1/templates` |
| `add_contact(email, ...)` / `list_contacts(...)` | `/v1/contacts` |
| `suppress(email, reason)` | `POST /v1/suppressions` |
| `usage()` / `health()` | `/v1/usage`, `/health` |

## Errors

Failed requests raise `SendFlitError`, with `.status` and `.body`. See [Errors, retries and limits](/reference/errors).
