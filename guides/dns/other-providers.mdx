---
title: "Add SendFlit DNS records at any provider"
description: "The same steps work at any DNS provider: find the DNS page for your domain, add three TXT records, then verify."
---

Your provider isn't in the list? The steps are the same at every DNS host. Only the menu names change. Use the values from your SendFlit dashboard, and add them as TXT records.

## Before you start

- The DNS records for your domain, from **Domains** in the SendFlit dashboard.
- Access to the DNS settings for the domain. Look for words like **DNS**, **DNS records**, **Zone**, or **Manage DNS** in your provider's menu.

## Steps

<Steps>
  <Step title="Open the DNS page for your domain">
    Find the page where your provider lists the records for the domain. It's usually called **DNS**, **DNS records**, **Zone file**, or **Advanced DNS**.
  </Step>
  <Step title="Add the DKIM record">
    Type: **TXT**. Name: `sendflit._domainkey` (or the name the dashboard shows). Value: copy the full value from the dashboard.
  </Step>
  <Step title="Add the sending (SPF) record">
    Type: **TXT**. Name and value: copy both from the **Enable sending** section of the dashboard. The name is either the root domain (`@`) or your return-path subdomain (for example `send.yourdomain.com`). Use the name the dashboard shows.
    If a record already starts with `v=spf1` on the same name, don't add a second one. Merge the new part into it.
  </Step>
  <Step title="Add the DMARC record">
    Type: **TXT**. Name: `_dmarc`. Value: copy it from the dashboard.
  </Step>
  <Step title="Save and verify">
    Save the records, then verify the domain in the dashboard with **Verify DNS records**, or with the API:

    ```bash
    curl -X POST https://api.sendflit.com/v1/domains/<domain_id>/verify \
      -H "Authorization: Bearer $SENDFLIT_KEY"
    ```
  </Step>
</Steps>

## Tips for any provider

- **Names:** some providers add your domain automatically, so enter only the part before it. Use `@` or leave the name blank for the root.
- **Long values:** a DKIM value can be longer than 255 characters. If your provider rejects it, split it into quoted chunks separated by a space.
- **Quotes:** paste the value without extra quotes unless the provider asks for them.
- **Wait:** changes can take up to a few hours. Verify again after a while.

## Check the records yourself

```bash
dig TXT sendflit._domainkey.yourdomain.com +short
dig TXT yourdomain.com +short
dig TXT _dmarc.yourdomain.com +short
```

Each command should print the value you added.
