## How it works

1. **Verify a domain.** Publish three DNS records so receiving servers trust your mail. See [Domains](/concepts/domains).
2. **Create an API key.** Choose the smallest scope the key needs. See [API keys](/concepts/api-keys).
3. **Send.** Call the API, an SDK, or SMTP. Each send returns an `id` you can track.
4. **Listen.** Subscribe to [webhooks](/reference/webhooks) for delivery, bounce, and complaint events, and suppress addresses automatically.

## Choose how to integrate

| You have | Use |
|---|---|
| An application in a supported language | An [SDK](/sdks/node) |
| An app or device that only speaks SMTP | The [SMTP relay](/guides/smtp) |
| An existing Resend integration | [Switching from Resend](/guides/switching-from-resend) |
| An AI agent that should send email or manage contacts | The [MCP server](/guides/mcp-server) |
| Any other HTTP client | The [REST API](/reference/api-overview) |
